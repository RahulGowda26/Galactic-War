# Galactic War: The Last Stand

A space-combat game built for an immersive, level-based campaign.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:

   ```bash
   npm install
   ```

2. Configure your environment:

   Set your `GEMINI_API_KEY` in `.env.local`.

3. Start the development server:

   ```bash
   npm run dev
   ```

## Project

Galactic War: The Last Stand is a space-combat experience featuring enemy encounters, escalating challenges, and campaign progression.

---

**Note:** Never commit `.env.local` or expose your API keys.
